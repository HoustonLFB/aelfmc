# AELF MC

**AELF MC** affiche automatiquement les informations liturgiques du jour directement dans le **Message Of The Day (MOTD)** de votre serveur Minecraft.

## Fonctionnement

Le mod récupère chaque jour les données du calendrier liturgique via l'API de l'AELF (Association Épiscopale Liturgique pour les pays Francophones).

- La **première ligne** du MOTD est celle définie dans votre fichier `server.properties`.
- La **deuxième ligne** affiche le jour liturgique en cours, dans la couleur liturgique correspondante.

## Fonctionnalités

- Mise à jour automatique quotidienne du jour liturgique.
- Prise en charge de toutes les couleurs du calendrier liturgique catholique romain.
- Aucun paramétrage requis après l'installation.
- Aucun traitement ni collecte de données personnelles.
- Code source libre et gratuit.
